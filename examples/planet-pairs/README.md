# Planet Pairs

Remember where the little space souvenirs are hiding.

- Ages: 3–7
- Learning: Visual memory
- Activity: memory

Turn over two cards. Match their pictures or their related meanings.

Play locally with `pnpm examples:serve`, then select this game at http://localhost:4173. Rebuild graphics with `pnpm --dir examples/planet-pairs assets`. Shared source and full build instructions: [studio](../_studio/README.md).

Each public folder is a standalone shipment with local assets, speech (where the browser supports it), synthesised sound, keyboard controls, and no network calls beyond the store’s Three.js vendor. Deploy with `node examples/publish.mjs planet-pairs` after installing workspace dependencies.
