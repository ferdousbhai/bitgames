# Comet Tail Measure

Measure sparkling comet tails without gaps.

- Ages: 5–8
- Learning: Measuring with consistent units
- Activity: measure

Place equal units along the glowing length without gaps. Press Check.

Play locally with `pnpm examples:serve`, then select this game at http://localhost:4173. Rebuild graphics with `pnpm --dir examples/comet-tail-measure assets`. Shared source and full build instructions: [studio](../_studio/README.md).

Each public folder is a standalone shipment with local assets, speech (where the browser supports it), synthesised sound, keyboard controls, and no network calls beyond the store’s Three.js vendor. Deploy with `node examples/publish.mjs comet-tail-measure` after installing workspace dependencies.
